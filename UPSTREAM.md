## What we use

`packages/balance-engine` (`@autumn/balance-engine`): Autumn's balance rules as pure functions (`compute*`: subject + command in, decision or mutation out). It imports 38 names from `@autumn/shared`; a static, file-level import walk of those reaches 1,208 of `shared`'s 1,292 files (about 74,000 lines), with `zod`, `decimal.js`, `drizzle-orm`, `stripe`, `date-fns`, `better-auth` and `@orpc/*` among the packages they import. Extracting the engine alone is therefore not a copy of a few files: `atm` stays inside this workspace, and a bundled build (`bun build`) is what tree-shakes it down. `bun run --cwd packages/atm build` gives the CLI (`dist/atm.js`, about 2 MB) and the library (`dist/index.js`, about 1.9 MB, plus `index.d.ts` and `types.d.ts`), each one file with the engine and only what it reaches. The library's types are atm's own (`src/types.ts`): the engine's declarations import `zod/v4` and `@autumn/shared` hundreds of times, and bundling them (dts-bundle-generator) failed to resolve the engine's imports, so atm declares plain JSON shapes and a test checks the engine's types still fit them.
